# Sports Sidebar

Chrome extension keeping you updated with live sports scores while you browse. Lightweight, non-intrusive sidebar for real-time game tracking.

  <img src="demo.png" alt="Sports Sidebar screenshot" />

## How to use

1. Install the extension from the [Chrome Web Store](https://chromewebstore.google.com/detail/sports-sidebar/cdobdanfodbnnipopddpmhllajndjiko).
2. Click the Sports Sidebar icon in the Chrome toolbar to open the sidebar.
3. Open the options menu by clicking "Options."
4. Choose your sport and date.
5. Customize display settings with the checkboxes:
   - **Hide Finished Events** — hide events that already finished.
   - **Hide Not Started Events** — hide events that have not started yet.
   - **Show Long Names** — show full team names.
6. View live scores directly in the sidebar. Click an event to open a new SofaScore tab with full details.

## How it works

Settings save through cookies. This keeps your preferences the same across sessions.
